# TranscribeAI interface

Personal meeting archive workbench: an archive rail, one conversation column, persistent scope selector, and an original-transcript dialog. The main task is recalling a discussion and verifying it against timestamps; upload and search remain one action away.

Use a restrained white/slate surface with indigo actions and green indexing readiness. Manrope headings and DM Sans body use system font fallbacks. Sources are compact text rows, not dashboard cards. No decorative data graphics or generic metrics. Conversations, original transcripts and operational states are the content.

Spacing: 4/8/12/16/24/32 px rhythm. Controls use 6–8 px corners; dialogs 14 px. Focus outlines are visible. Dialogs use native modal focus containment and Escape dismissal; upload remains open during a request. Source clicks highlight an entire cue interval and scroll the transcript to it.

At 720 px the archive becomes an explicit menu drawer. Compose and scope remain reachable. Text wraps, timestamps use tabular numerals, touch targets preserve usable padding, and reduced-motion preferences disable motion. No browser persistence; reload reads durable backend state.

Markdown blockquotes retain a subtle border for semantic quotation readability.
